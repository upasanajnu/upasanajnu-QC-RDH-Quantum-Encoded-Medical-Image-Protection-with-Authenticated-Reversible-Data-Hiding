# upasanajnu-QC-RDH-Quantum-Encoded-Medical-Image-Protection-with-Authenticated-Reversible-Data-Hiding
Official implementation of QC-RDH, an authenticated reversible data hiding framework for quantum-encoded medical images, featuring a unitary diffusion bound, chosen-cover cryptanalysis, nonce-based encryption and authentication, and gate-level verified NEQR construction.
